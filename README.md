# Mathematical Modeling — 数学建模常用算法的Python实现（尚在更新中）

本项目逐步更新数学建模竞赛与科研中常用的算法，使用 Python 实现。

- 算法将会依据示例问题及相关数据来设计。

- 本项目为个人学习记录，后续会逐步更新。

## 项目结构

算法会逐步更新，每个算法目录下包含：
- **核心代码**（`.py`）— 完整可运行的实现
- **Notebook**（`.ipynb`）— 逐步讲解，适合学习
- **问题数据**（`.csv`）— 可直接运行测试
- **问题给出**（`.md`）— 给出该算法的一个问题示例
